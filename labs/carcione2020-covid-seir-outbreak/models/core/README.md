        # Carcione2020 - Deterministic SEIR simulation of a COVID-19 outbreak

        Curated Biosimulant epidemiology core model.

        The bundled SBML/XML source file remains the scientific source of truth.
        The Python wrapper uses `biosim.contrib.sbml.TelluriumSBMLBioModule` and
        exposes conservative, traceable Biosimulant ports.

        Upstream source: `biomodels_ebi:BIOMD0000000974`
        Original URL: https://www.ebi.ac.uk/biomodels/BIOMD0000000974

        Selected observables:
        - `Exposed`: Expo ed
- `Infected`: Infected
- `Deceased`: Decea ed
- `Susceptible`: Su ceptible
- `Recovered`: Recovered
- `Total_population`: Total population
