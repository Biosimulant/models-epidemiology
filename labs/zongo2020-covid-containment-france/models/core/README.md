        # Zongo2020 - model of COVID-19 transmission dynamics under containment measures in France

        Curated Biosimulant epidemiology core model.

        The bundled SBML/XML source file remains the scientific source of truth.
        The Python wrapper uses `biosim.contrib.sbml.TelluriumSBMLBioModule` and
        exposes conservative, traceable Biosimulant ports.

        Upstream source: `biomodels_ebi:BIOMD0000000983`
        Original URL: https://www.ebi.ac.uk/biomodels/BIOMD0000000983

        Selected observables:
        - `S_u`: Su ceptible unconfined
- `I_u`: Infected unreported
- `S_c`: Su ceptible confined
- `E`: Exposed
- `I_r`: Infected reported
- `R`: Recovered
- `Q`: Quarantined
