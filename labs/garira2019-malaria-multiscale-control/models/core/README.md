        # Garira2019 - A coupled multiscale model to guide malaria control and elimination

        Curated Biosimulant epidemiology core model.

        The bundled SBML/XML source file remains the scientific source of truth.
        The Python wrapper uses `biosim.contrib.sbml.TelluriumSBMLBioModule` and
        exposes conservative, traceable Biosimulant ports.

        Upstream source: `biomodels_ebi:MODEL2003190008`
        Original URL: https://www.ebi.ac.uk/biomodels/MODEL2003190008

        Selected observables:
        - `S_H`: Susceptible human
- `I_H`: Infected human
- `P_V`: P vector
- `S_V`: Susceptible vector
- `I_V`: Infected vector
- `G_H`: G human
