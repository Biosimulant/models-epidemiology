        # Ndii2015-transmission dynamics of dengue in the presence of Wolbachia

        Curated Biosimulant epidemiology core model.

        The bundled SBML/XML source file remains the scientific source of truth.
        The Python wrapper uses `biosim.contrib.sbml.TelluriumSBMLBioModule` and
        exposes conservative, traceable Biosimulant ports.

        Upstream source: `biomodels_ebi:MODEL2003160002`
        Original URL: https://www.ebi.ac.uk/biomodels/MODEL2003160002

        Selected observables:
        - `S_H`: Susceptible human
- `E_H`: Exposed human
- `I_H`: Infected human
- `R_H`: Recovered human
- `S_N`: Susceptible non-Wolbachia
- `I_N`: Infected non-Wolbachia
- `S_W`: Susceptible Wolbachia
- `I_W`: Infected Wolbachia
