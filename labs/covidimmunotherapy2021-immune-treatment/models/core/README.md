        # COVID-19 immunotherapy A mathematical model

        Curated Biosimulant epidemiology core model.

        The bundled SBML/XML source file remains the scientific source of truth.
        The Python wrapper uses `biosim.contrib.sbml.TelluriumSBMLBioModule` and
        exposes conservative, traceable Biosimulant ports.

        Upstream source: `biomodels_ebi:MODEL2109130003`
        Original URL: https://www.ebi.ac.uk/biomodels/MODEL2109130003

        Selected observables:
        - `I_ab_tratamento`: Infected ab(tratamento)
- `V_tratamento`: V(tratamento)
- `A_I_tratamento`: Asymptomatic I(tratamento)
- `N_at_tratamento`: Non-Wolbachia at(tratamento)
- `I_12_tratamento`: Infected 12(tratamento)
- `B_tratamento`: B(tratamento)
- `Inib_tratamento`: Inib(tratamento)
